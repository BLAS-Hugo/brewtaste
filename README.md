# BrewTaste 🍺

Mobile app for organizing blind beer tasting sessions with friends.

## Features
- Create tasting sessions with a shareable code or QR
- Blind or non-blind mode
- Real-time voting and guessing
- Simultaneous results reveal

## Tech stack
- Flutter (Android & iOS)
- Appwrite
- Riverpod + GoRouter
- Sentry
